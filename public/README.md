# SPEED — Cinematic 3D concept landing

Proyecto de demostración **no oficial**, no afiliado a la marca SPEED. La lata utiliza una etiqueta estilizada generada con Canvas, no una reproducción exacta del envase comercial.

## Ejecutar en Windows

```powershell
npm.cmd install
npm.cmd run dev
```

Abrir http://localhost:3000

## Detalles

- Lata 3D con etiqueta negra, blanca y roja, orientada al frente.
- Movimiento suave con mouse y scroll.
- Escena de partículas, iluminación y anillos animados.
- Responsive.

Para un modelo idéntico al producto real hace falta una textura oficial de alta resolución o un modelo 3D autorizado.
